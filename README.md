# Assembly-grapher

- `docs/`: build log for the AI companion computer on an analog FPV quad (GitHub Pages).
- [`airframe/`](airframe/README.md): **Kipinä 450**, a 450 mm, 3D-printed twin-tube
  FPV fixed wing with ailerons, elevator and twin rudders on four SG90 servos,
  generated from parametric CadQuery code (STLs, STEP assembly with
  electronics, sizing report). Every part prints on a Bambu Lab A1 mini. It
  also has a bill of process with its precedence graph, an assembly animation
  and a DFMA analysis.
