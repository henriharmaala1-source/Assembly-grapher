Design efficiency = 3 s x theoretical minimum parts / actual assembly time. Handling and inserting parts is only a fifth of the assembly time; gluing, soldering, taping and bending take the rest, so the biggest wins remove joints, not just parts.

A part counts toward the theoretical minimum when it moves relative to the parts already assembled, must be a different material, or must be separate for assembly or service.

The whole printed airframe, wing included, is only 100 g of filament: the wing sections are thin one-wall LW-PLA shells (42 g for the centre, both panels and both ailerons). So the filament per airframe is a few euros, but a first build still has to buy the spools:

Budget some LW-PLA for calibration: test cubes to set the flow, and possibly a failed 1.5-hour wing panel. Later airframes from the same spools cost the bought parts plus a few euros of filament.
